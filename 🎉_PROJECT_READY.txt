┌──────────────────────────────────────────────────────────────────────────────┐
│                          💡 KEY TECHNICAL DECISIONS                          │
└──────────────────────────────────────────────────────────────────────────────┘

WHY TAURI?
   → 90% smaller than Electron (~10MB vs ~120MB)
   → 50% less RAM usage
   → Native OS webview (faster startup)
   → Perfect for low-spec retail PCs

WHY SQLITE?
   → No SQL Server required (easier deployment)
   → Single-file database
   → 100% offline operation
   → ACID transactions

WHY VUE 3?
   → Modern reactive framework
   → Composition API (better TypeScript)
   → Smaller bundle than React
   → Excellent performance

WHY DIRECT SQL?
   → Simpler than ORM
   → No Node.js dependency
   → Full SQL control
   → Works in Tauri WebView
