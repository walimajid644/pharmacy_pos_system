# Receipt Preview - Thermal Printer Format

## Where to View

You can now see the updated thermal receipt format in **two places**:

### 1. Settings → Receipt Tab ✅
Navigate to: **Settings** → **Receipt** tab

The preview section shows the new thermal receipt format with:
- Date/Time and cashier name header
- Payment mode display
- BILL/CASH MEMO section
- Invoice number
- Client name
- Item table with proper columns (ITEM NAME, QTY, RATE, AMT)
- Items count and gross total
- Thank you message
- Final total
- Footer with disclaimer

### 2. After Completing a Sale
When you complete a sale in the POS terminal, the receipt will automatically print in this new format.

## Features

✅ **Compact Layout**: Optimized for 80mm thermal paper
✅ **Clear Alignment**: Item names left, quantities centered, amounts right-aligned
✅ **Professional Design**: Matches standard pharmacy POS receipts
✅ **Batch Numbers**: Shown below item names in smaller text
✅ **Summary Section**: Items count and gross with clear borders
✅ **Footer**: Standard disclaimer and developer credit

## How to Access

1. **Open the Application**
2. Navigate to **Settings** (gear icon or settings menu)
3. Click on the **"Receipt"** tab
4. Scroll down to see the **"Receipt Preview"** section

You'll see a live preview of how the thermal receipt will look with the current settings!

## Customization

In the Receipt Settings, you can customize:
- Receipt header (optional)
- Receipt footer (optional)
- Show/hide DRAP registration numbers

The preview will update to show your customizations in the new thermal format.
